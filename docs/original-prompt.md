I want to make my own version of https://github.com/ahujasid/ableton-mcp
it will be meant as portfolio work and a tool I will actually use so we need to get it ready to go public and be open source and be contributable and all scoped to the size of the project, small for now.

Along with what that mcp can already do my main want and concern is to be able to have claude (or any other llm) setup a scene or stack of vsts or fill a drum rack for me. I want it to be able to help me organize and label things based on categories or even how frequently something is used if possible. I want to make this fully featured.

The intention is not to turn ableton live into a fully automatable and controllable surface for ai but to allow as close to as native control as we can for llms to assist the user in using the program or applying ideas and such.

For example I want to be able to tell it I want to look at my recent dance-genre projects to pick out which drum one shots I'm actually using and make a drumrack out of it in a standard drumrack format to make it easier to transfer midi from another rack to this one, like kicks in the standard spots, snares , etc...

Another example I want to be able to do is to be able to apply color tags to plugins I regularly use to make it easier for me to sort by common ones I use.

Another example is if I read an article about how a particular artist (Future for example) does their vocal chain including the software and hardware. I want to ask to be able to replicate it as close as possible with my current VSTs. So it could look and see what hardware it is, what are direct emulations of it that I have access to, or if not what are the closest alternatives I have to it. Then even attempting to dial in the settings of each the best we can too.

Another example is a lot of tracks I have a bunch of fx on them but i want to make it more expressive and reuse them but I am too lazy to put them in an Audio Group and setup proper macro mappings and all that. Would be awesome to point it at a track fx chain, say something like "I want the fx all grouped up and I want the following knobs to be labeled and mapped appropriately for our macros; Riser FX, Dub Delay FX, and the rest whatever makes sense" and then maybe describe what i mean that Riser FX I normally do like; mono to stereo 0.0-1.0, reverb dry/wet 0.0-1.0, pitch up 0.0-12.0 semitones, etc... 

I hope that gives you a good idea of my goals with this. Make sure we record all of this out and can reference this exact raw prompt in the future to ensure we don't drift.
